# 演示动画补全记录

## 对照与实现

对照用户提供的 39.43 秒演示视频：舞台约 6–15 秒，乐器分类与详情约 18–25 秒，乐理转盘约 27–32 秒。依用户确认，点选舞台乐器直接加入／移出该声部，转盘采用底部局部露出的布局。

- 舞台的 12 个按钮、12 个角色遮罩与原有声部音频共用阵容状态。选中恢复彩色并短暂高亮，取消用 240ms 淡变压暗；角色按钮支持键盘，详情由独立信息按钮打开。
- 遮罩使用原图 393 × 345 坐标。透明角色素材 `orchestra-characters.png` 在原舞台图中精确对应 `(13, 80)`、大小 `365 × 205`，与逐人轮廓及前景遮挡相交，保持舞台背景不变。
- 原有音频引擎继续负责同步播放；补上异步操作失效检查，使用同步阵容引用处理批量点选，并避免旧播放请求重新启动已移除的声部、覆盖新阵容的错误状态。
- 乐理圆盘、刻度、图标及指示装饰分别绘制。三个章节间以 32° 步距、420ms 时长旋转，图标反向补偿保持正向；切章正文过渡 280ms。其余图标仅装饰。
- 转盘通过 portal 固定在手机画幅内和底部导航上方；移出章节重建区域，并取消整个主内容区的路径 key，避免旋转重置。正文预留末尾滚动空间。
- 页面进出采用可取消的 320ms 动画，分类内容与标签同步过渡；分类查询变化不触发整个页面的第二层动画。场景颜色平滑变化，减少动态效果设置下直接显示最终状态。
- 未新增外部 API、依赖或教学章节；未修改现有 3D 模型入口，未发布线上版本。
