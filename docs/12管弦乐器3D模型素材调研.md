# 12 管弦乐器 3D 模型素材调研

整理日期：2026-05-27

## 1. 项目内现状

当前项目已经有《睡美人圆舞曲》12 条分轨，对应的乐器在 `src/data/sleepingBeauty.ts` 和 `src/data/orchestraDemo.ts` 里维护：

| id | 中文名 | 声部 |
| --- | --- | --- |
| `flute` | 长笛 | 木管 |
| `clarinet` | 单簧管 | 木管 |
| `oboe` | 双簧管 | 木管 |
| `bassoon` | 巴松 | 木管 |
| `horn` | 圆号 | 铜管 |
| `trumpet` | 小号 | 铜管 |
| `trombone` | 长号 | 铜管 |
| `tuba` | 大号 | 铜管 |
| `violin` | 小提琴 | 弦乐 |
| `viola` | 中提琴 | 弦乐 |
| `cello` | 大提琴 | 弦乐 |
| `bass` | 低音提琴 | 弦乐 |

本地目前只有一个正式接入的占位 3D 模型：

```text
public/assets/models/softmind/scene.gltf
```

`src/data/entries.ts` 里的 3 个条目现在都把 `modelUrl` 指向这个占位模型。MindAR 页面通过 `modelUrl` 加载模型，所以正式替换时只需要把模型放进 `public/assets/models/`，再把条目的 `modelUrl` 改成对应路径。

## 2. 推荐接入格式

项目现有 WebAR 方案优先使用：

1. `glb`
2. `gltf`

如果下载到的是 `.fbx`、`.obj`、`.blend`、`.stl`，建议先用 Blender 检查比例、轴向、贴图路径和面数，再导出成 `.glb`。移动端 WebAR 建议单件乐器尽量控制在 5 万面以内。

建议目录：

```text
public/assets/models/flute/scene.glb
public/assets/models/clarinet/scene.glb
public/assets/models/oboe/scene.glb
public/assets/models/bassoon/scene.glb
public/assets/models/horn/scene.glb
public/assets/models/trumpet/scene.glb
public/assets/models/trombone/scene.glb
public/assets/models/tuba/scene.glb
public/assets/models/violin/scene.glb
public/assets/models/viola/scene.glb
public/assets/models/cello/scene.glb
public/assets/models/bass/scene.glb
```

## 5. 授权检查清单

正式放进项目仓库前，至少记录这些信息：

| 字段 | 说明 |
| --- | --- |
| 模型来源 URL | 具体模型页，不只记录搜索页。 |
| 作者 / 商家 | 用于署名和后续追溯。 |
| 许可证 | CC0、CC BY、Standard License、Royalty Free、Personal/Education 等。 |
| 是否可商用 | 如果将来要公开部署、参赛、展陈或商业合作，必须明确。 |
| 是否需要署名 | CC BY 通常需要署名，署名文本可放到关于页或素材说明页。 |
| 下载格式 | 记录原始格式和最终导出的 `.glb` 路径。 |
| 面数与贴图尺寸 | 移动端 AR 性能审核用。 |

不建议使用没有明确下载按钮、没有授权说明、疑似游戏/影视提取、或者只能通过第三方抓取工具获得的模型。

## 6. 下一步建议

1. 先确定是“统一购买套装”还是“免费素材拼装”。
2. 下载前按上面的 12 件乐器逐个确认许可证。
3. 每个乐器先只导出一个 `scene.glb`，放进 `public/assets/models/<instrument>/`。
4. 用 Blender 批量减面、归一化尺寸和轴向。
5. 在 `src/data/entries.ts` 或新增 12 乐器条目时，把 `modelUrl` 指向对应模型路径。
